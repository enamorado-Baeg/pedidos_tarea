# Sistema de Gestión de Pedidos

Aplicación web sencilla para administrar un inventario y registrar pedidos. Permite consultar las existencias, agregar productos con su cantidad y precio, y descontar del inventario las unidades de cada pedido. El total se muestra en lempiras (L.).

## Tecnologías

- HTML
- CSS
- JavaScript (sin dependencias externas)

## Uso

Abre `pedidos.html` en un navegador moderno. El inventario inicial contiene arroz, frijoles y azúcar. Los cambios se mantienen solo mientras la página está abierta; al recargarla, se restaura el inventario inicial.

## Trabajo colaborativo

1. Crea una rama para cada cambio y abre un pull request hacia `main`.
2. Antes de fusionarlo, otro integrante debe revisar el cambio y dejar al menos un comentario específico, respetuoso y accionable. El comentario debe referirse al código y, cuando corresponda, explicar el motivo y sugerir una mejora.
3. Atiende las observaciones y fusiona el pull request en `main` una vez aprobado por el revisor.

No se debe aprobar ni fusionar un pull request propio como sustituto de la revisión por otro integrante.
